# LinkGuard - Phishing website Detection

 LinkGuard is a python-based web application designed to help users identify potentially
 malicious URLs and improve their awereness of phishing threats

## Installation

To install and run VeriScope, follow these steps:

1. Clone the repository:

```bash
git clone <repository_url>
cd veriscope_modified
```

2. Create a virtual environment and activate it:

```bash
python -m venv venv
.\venv\Scripts\activate
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

## Usage

After running the application, open your web browser and navigate to `http://127.0.0.1:3000` to access VeriScope. You can then input a URL to check if it's a phishing site.
